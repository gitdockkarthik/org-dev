Platform Observability

📊 Langfuse Overview

Self-hosted LLM observability, cost governance, and audit trail for all agents

No Data Leaves Platform

Langfuse is self-hosted within your infrastructure. All traces, tokens, costs stay internal — no cloud dependency.

Universal Tracing

Every LLM call across all agents traces automatically via shared/llm.py — no custom instrumentation per agent.

Cost Governance

Track LLM spend per agent, per user, per model in real-time. Cost is calculated and surfaced immediately in Portal.

What is Langfuse?

Langfuse is an open-source LLM observability platform designed for teams building AI applications. It:

  • Traces every LLM interaction: Request, response, token counts, latency, errors
  • Calculates costs: Based on token usage and model pricing
  • Groups conversations: Session ID groups related calls for conversation context
  • Self-hosted: Runs entirely within your infrastructure via Docker Compose
  • No data leakage: All data stays internal; no cloud sync or external APIs (except Anthropic for LLM calls)

Why We Use It

Token Cost Governance

LLM costs scale with usage. Langfuse tracks every token and calculates cost per call, per agent, per user. Portal admins can see total spend and identify cost outliers immediately.

Agent Maturity Tracking

As agents evolve, their model calls change. Langfuse provides historical performance data: latency trends, error rates, token efficiency. This enables data-driven agent optimization.

Audit Trail

Compliance and internal audits require proof of what LLM calls were made, when, by whom, using which model, with which inputs. Langfuse is the source of truth.

Platform-Level Tracing

Every agent uses shared/llm.py to call Claude. This shared module automatically instruments all LLM calls, ensuring consistent tracing across the entire platform with zero per-agent overhead.

What Gets Tracked

For every LLM call, Langfuse captures:

Field Example Purpose
Agent alert-analyser Identify which agent made the call
Model claude-sonnet-4-6 Track model choice and pricing tier
Input Tokens 1,250 Tokens sent to Claude (prompt size)
Output Tokens 350 Tokens returned by Claude (response size)
Total Tokens 1,600 Sum of input + output for quick reference
Cost (USD) $0.0048 Calculated cost based on model + tokens
User Email user@operative.com Portal user who invoked the agent
Session ID chat-session-123 Groups related calls in the same conversation
Timestamp 2026-07-26T11:30:45Z When the call was made
Latency 1,250 ms Time from call to response
Tool Calls get_data, transform_data Tools executed by the agent (if any)
Errors RateLimitError Exception type if call failed

Key Points

  • Agents never import Anthropic SDK directly: All Claude calls go through shared/llm.py
  • Tracing is automatic: Langfuse instrumentation happens inside shared/llm.py
  • Zero-failure design: If Langfuse is down, agents still work (traces are dropped, but Claude calls succeed)
  • Session grouping: Pass session_id to group calls in the same chat

Viewing in Portal

Location

Navigate to Admin → Audit → LLM Usage tab to see all LLM calls across all agents.

Filters & Date Range

  • Date range: Last 24 hours, 7 days (default), 30 days, or all time
  • Agent filter: Show calls from a specific agent only
  • User filter: Show calls by a specific user
  • Model filter: Show calls to a specific Claude model

Metrics Visible

  • Total Calls: Number of LLM invocations in the selected period
  • Total Tokens: Sum of all input + output tokens
  • Total Cost: Aggregate cost in USD
  • Avg Cost/Call: Average cost per LLM call
  • Per-call details: Timestamp, agent, user, model, input/output/total tokens, cost, session
